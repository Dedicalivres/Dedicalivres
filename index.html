      Confidentialité et effacement

      Seuls le pays, la région et le type choisis sont mémorisés pour le suivi, pas le texte de recherche, le mois ni la position. Aucune notification n’est envoyée lorsque le site est fermé.

      Vos favoris et critères restent dans ce navigateur, sur cet appareil. Ils peuvent être perdus si vous effacez les données du site ou utilisez la navigation privée. Les personnes utilisant ce même profil de navigateur peuvent les consulter. Aucun e-mail n’est envoyé pour ces suivis.
