# Le Passage — architecture narrative V0

## 1. LA PORTE
**Tu viens d'ouvrir une porte.**

Une rencontre peut commencer par un simple geste.

Tracking : `nfc_open`, `nfc_scene_view:door`.

## 2. LA RENCONTRE
**Les livres ne sont pas faits seulement pour être lus. Ils créent des rencontres.**

Mots : Salons · Festivals · Dédicaces · Rencontres · Auteurs · Lecteurs.

## 3. DÉDICALIVRES
**Dédicalivres rend ces rencontres visibles.**

Un agenda littéraire gratuit et participatif pour savoir où les livres prennent vie.

## 4. LA PROXIMITÉ
**Et certaines rencontres sont peut-être beaucoup plus proches que tu ne le crois.**

CTA : **Voir autour de moi**.

La géolocalisation n'est demandée qu'après le clic. Refus = fallback agenda. Évolution : afficher dans le sas le nombre réel d'événements dans 25 km et la prochaine rencontre.

## 5. MON USAGE
**Qu'est-ce qui t'amène ici ?**

- Découvrir autour de moi
- Garder mes prochaines rencontres
- Je participe au monde du livre
- Simplement découvrir Dédicalivres

Le troisième choix peut préciser auteur/artiste-auteur, organisateur, librairie/éditeur/partenaire.

## 6. LE PASSAGE
Transition noir/améthyste/émeraude → crème/violet officiel/accent orange.

**La porte est ouverte.**

CTA principal : **Entrer dans Dédicalivres**.

CTA secondaire contextuel : proximité, favoris, auteur, organisateur ou découverte.

## Première activation sur le site
Une arrivée ne suffit pas. Activation = favori ajouté, proximité utilisée, fiche ouverte, soumission commencée ou présence auteur commencée.
