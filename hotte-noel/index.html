    Qui déclenche le tirage ?

    En laboratoire, l’administrateur prépare le gel puis lance le tirage uniquement depuis le terminal local. Le résultat devient ensuite visible ici. Le site public ne peut pas déclencher un nouveau tirage.

    Voir le protocole administrateur

    01Liste figée

    Engagements cryptographiques de numéros, jamais les e-mails.

    02Hasard indépendant

    Graine externe annoncée après gel ; animation sans influence.

    03Preuve exportable

    Résultat reproduit hors de l'animation.

    GESTION PRIVÉE

    Piloter le tirage sans compromettre ses preuves.

    Dans la version de laboratoire, les décisions sont prises dans le terminal privé : revue des inscriptions suspectes, gel des numéros admis, puis tirage avec une graine indépendante postérieure au gel.

    1. Examiner et résoudre les alertes de doublons.
    2. Figer la liste, constater son empreinte avant la graine externe.
    3. Déclencher le tirage local puis vérifier et publier uniquement les numéros.

    Aucun accès administrateur public ni date de tirage n’est activé.
